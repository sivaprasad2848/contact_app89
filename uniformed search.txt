bfs:
1. set a starting node
2, initialize fifo que for starting node
3. initialize the explored set too avoid reprocessing states 
4. loop until the queue is empty
5. expand the current node and neighbours

dfs:
1. exploring all possible connectivity
algorithm of dfs:
1. pick a starting node and mark it as visited
2. push it on to the stack
3. explore an unvisited neighbor
4. backtrack when stuck 
5. repeat until the stack is empty
