alpha beta  pruning
- optimization technique used in min max algorithm
- pruns means eliminate
- it avoids the unnecessary branch in tree so that we can speed the search time

Alpha:
- the best highest value max is guaranteed
Beta:
- the lowest min is guaranteed
pruning condition:
- whenever alpha greater than or equal beta the current branch can be safely cut off
- because the opponent could never allow the game to enter this
